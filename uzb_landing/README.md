# Авиабилеты Узбекистан — Россия | Прототип лендинга tutu.ru

Прототип лендинга для потенциального выхода tutu.ru на рынок пассажирских перевозок между Узбекистаном и Россией. Сделан на чистом HTML/CSS/JS (без сборки, без зависимостей) в рамках проектной работы (Milestone 3: тестирование гипотез лендинга).

## Как открыть

Просто откройте `index.html` в браузере — никакой установки не требуется.

Либо включите GitHub Pages для этого репозитория (Settings → Pages → Source: `main` / `/ (root)`), и лендинг будет доступен по публичной ссылке вида `https://<ваш-логин>.github.io/<репозиторий>/`.

## Структура

- `index.html` — разметка страницы
- `src/data.js` — данные (города, маршруты, хостелы, полезная информация, переводы RU/UZ)
- `src/app.js` — логика (поиск, рендер карточек, переключение языка, попап пассажиров и т.д.)
- `src/styles.css` — стили

## Что внутри

- Двуязычный интерфейс (русский / узбекский), переключение без перезагрузки страницы.
- Форма поиска авиабилетов (города, даты, пассажиры, класс обслуживания).
- Карточки популярных направлений Узбекистан ↔ Россия с ценами в рублях и сумах, названием авиакомпании.
- Блок «Где остановиться» — карточки хостелов.
- Блок «Полезно знать по приезде» — чек-лист для трудовых мигрантов/студентов.
- Промо-блок с промокодом на обратный билет.
- Все кнопки и карточки ведут на соответствующие боевые разделы tutu.ru (авиабилеты, отели, поезда, автобусы и т.д.).
- Плейсхолдер для Яндекс.Метрики в `index.html` (закомментирован, готов к активации — см. комментарий в файле).

## Основание

Гипотезы и решения по дизайну лендинга основаны на CustDev-интервью с трудовыми мигрантами и студентами (сегменты — потенциальные пользователи направления Россия ↔ Узбекистан). Подробности — в проектной документации (не входит в этот репозиторий).
